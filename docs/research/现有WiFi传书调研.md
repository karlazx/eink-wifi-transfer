# 现有 WiFi 传书调研

状态：调研记录，2026-10-20。本文记录行为与独立实现边界，不提供原应用资产。

## 调研对象与证据

- 实机：Likebook K78W，Android 8.1 / API 27。
- 原应用：`com.boyue.wifitransfer`，版本 1.0，系统应用，声明 min / target SDK 17，并使用 `android.uid.system` 共享用户标识。新应用不能依赖系统签名或私有权限。
- 证据来源：ADB 读取的包信息、实机界面，以及同一局域网访问原应用所提供页面后的 HTML / JavaScript 分析。
- 原 APK、网页、脚本、截图仅在工作区之外临时研究；本仓库不收录这些文件，也不记录真实 IP、SSID、书名或用户文件清单。
- 以下“脚本确认”说明客户端具备对应逻辑，不等同于完整实机端到端验证；自建探针的端到端结果另见下文。

## 功能盘点

| 功能 | 观察或证据 | 结论 |
| --- | --- | --- |
| 服务入口 | 实机界面显示 HTTP 地址，端口 8080、二维码、同 WiFi 提示 | 保留这一连接方式；新应用独立呈现 |
| 防休眠 | 实机使用提示及界面行为 | 服务界面可见时保持屏幕唤醒 |
| 快速查看 | 实机点击后提示确认跳转书架，确认后进入 `com.boyue.app.byreader.MainActivity` | 新应用用独立接收目录的文件列表承接，不复用原私有入口 |
| 文件选择 | 网页 file input 带 `multiple` | 支持多文件选择 |
| 上传队列 | 上传器 `maxconnections: 1` | 单个浏览器队列串行上传 |
| 上传进度、取消 | `progress`、`abort` 回调及行操作 | 原网页具备相应交互 |
| 列表、大小、下载、删除 | 列表请求、文件下载、删除前 `confirm` | 保留基本文件管理闭环 |
| 重名处理 | `checkFileName` 检查列表及队列并提示先删除 | 默认拒绝覆盖 |
| 格式限制 | `checkFileName` 白名单校验，大小写不敏感；后端接受自建 `.bin` 探针 | 前端限制已确认；不能据单个探针断言后端接受所有内容 |
| 拖拽 | 有实现函数，但 `dragUpload()` 启用调用被注释 | 不宣称原应用已支持；M1 不要求 |
| 退出 | 按返回提示确认关闭，弹窗期间 HTTP 仍可访问；确认回到书架后曾短暂可访问，随后连接被拒绝，服务查询为空 | 原应用确认退出后延迟停止，不是永久后台；新应用无需复制该延迟 |

白名单文案列出 15 种格式：EPUB、TXT、PDF、MOBI、AZW3、FB2、DOC、DOCX、HTML、CBZ、CBT、CBR、DJVU、DJV、RTF。脚本采用后缀正则匹配，未要求后缀前存在点号；它证明存在客户端限制，不能证明精确的后端文件策略。

## 自建探针验证

通过 HTTP multipart `POST /files`，使用 `fileName` 与 `newfile` 字段上传自行生成的 `.txt`（37 字节）和 `.bin`（256 字节）文件。两者均返回 200，`GET /files` 返回的 `name`、`size` 列表包含两文件；对应附件 GET 均为 200，下载字节的 SHA-256 与上传前一致。

ADB 确认实际接收位置为 `/sdcard/WifiTransfer`。之后使用 `POST /files/<探针名>` 和 `_method=delete` 删除两文件，均返回 200，并由 ADB 确认已清理。未修改、覆盖或删除用户既有文件。

| 探针 | 大小 | SHA-256 |
| --- | --- | --- |
| 自建 TXT | 37 字节 | `c20f85f3a1274ebe8c1e875bd514b54493d4d061754baaf589e42dd992d97fac` |
| 自建 BIN | 256 字节 | `40aff2e9d2d8922e47afd4648e6967497158785fbd1da870e7110266bf944880` |

结论：非白名单 `.bin` 可直接经后端上传，白名单至少存在于原网页端。未全面测试后端校验，不据此宣称其完全没有格式或内容限制。

调研结束时，自建探针均已清理，设备恢复到任务开始时的书架界面。

## M1 采用与差异

独立实现“阅读器启动服务 → 浏览器访问 → 上传 / 列表 / 下载 / 确认删除”的闭环，保留二维码、进度、串行队列、取消和重名拒绝。主要功能变化是取消扩展名及 MIME 白名单，允许任意内容字节和无扩展名文件。

已确认的存储目录为共享存储 `EInkTransfer`，有意区别于原应用的 `/sdcard/WifiTransfer`。选择独立目录是为了避免覆盖或删除既有文件；M1 不导入、不迁移、不扫描原应用文件。原“快速查看”由新应用的接收文件列表承担，点击文件不承诺阅读、解析或安装。

返回保留关闭确认，取消后继续服务；确认后主动停止，不复制原应用短暂延迟。新应用明确切换到其他应用时停止服务，原应用这一场景尚未完整验证。目录隔离、快速查看目标和前台生命周期属于候选行为差异，与不限格式能力一起交由用户审批。

原应用的界面布局、图标、二维码图样、网页样式、脚本和 APK 均不作为开源素材。新应用代码、文案和视觉独立制作，仓库采用 MIT；第三方依赖另行保留其许可证。

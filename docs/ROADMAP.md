# 项目路线图

更新：2026-10-20。M1 范围已确认并实现；后续主题不代表交付承诺。用户已禁用 sdd-governance，后续不按其门禁执行。

| 阶段 | 目标 | 状态与出口 |
| --- | --- | --- |
| M1 不限格式传输 | 在 Android 8.1 墨水屏实机复现局域网传输闭环，取消格式白名单；独立目录、上传队列、列表、下载、确认删除；MIT 源码与可安装 APK | 已实现，完成必要实机与自动化验证后合并 main |
| M2 待定 | 按 M1 使用反馈选择优先需求，例如配对访问控制、保存目录选择或更好的连接反馈 | 不预定功能，先整理反馈并确认该迭代范围 |
| M3 及后续待定 | 可能探索后台传输、断点续传、文件夹与书库集成、更广设备兼容 | 分别评估系统限制与成本，不提前纳入 M1 |

每个新迭代从最新 `main` 新建独立开发分支；开发、修复与验证在该分支完成；通过必要验证后才合并。M1 分支为 `feature/m1-unrestricted-transfer`。

开源以独立实现、MIT 许可证、中文说明和不包含用户隐私为基本要求。原应用仅用于行为研究，不发布其 APK、代码、图片或其他原资产。公开仓库平台、名称和首次发布操作在具备可审查交付物后确定。

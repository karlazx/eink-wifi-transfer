主机接口测试覆盖：多种扩展名与任意字节、零字节、中文及 `% # & +` 文件名、下载 SHA-256 与附件头、精确删除、重名保护、并发同名、上传中断清理及重试、非法路径、符号链接越界、跨站 Origin / Host、无效长度请求。超上限测试仅发送长度声明，不生成或传输大文件。

网页逻辑测试覆盖：多选串行队列、特殊名称按文本展示、零字节、等待及上传中取消后继续、取消与提交竞态、同名拒绝、连接中断停止剩余队列、取消删除确认时不发请求。

实机样本包含 EPUB、TXT、PDF、PNG、ZIP、APK、TTF、自定义扩展名、无扩展名、零字节及特殊文件名；常规样本为自行生成的 16 KiB 任意字节，验证的是传输完整性，不是对应格式的内容解析。所有下载哈希与上传前一致。另验证并发重名、中断后可重传及列表完整性，未触碰原应用文件。

设备界面测试覆盖：拒绝存储权限后显示解释、授权后启动、接收列表可读且不停止服务、开源许可可读、返回确认与取消、确认退出停止服务、手动停止及重启、切换桌面停止、返回应用保留完成文件。上述 11 项界面自动检查之外，首次权限拒绝与授权恢复有单独的界面树证据。

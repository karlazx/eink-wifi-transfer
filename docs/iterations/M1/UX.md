# M1 文本原型与状态

状态：用户已确认首版范围；本文记录实现遵循的交互，实测结论另见 TEST_REPORT.md。

## UX-M1-001 阅读器主界面

```text
局域网文件传输                    [停止服务]
服务已开启
请让手机 / 电脑与本设备连接同一 WiFi
浏览器访问：http://<设备局域网地址>:8080
[上述地址的二维码]
保存位置：共享存储 / EInkTransfer
[查看接收文件]                    [刷新状态]

支持任意类型文件，仅负责传输。
仅在可信局域网使用；同网用户可访问和管理接收目录。
离开此界面会停止服务并中断未完成传输。
```

使用黑白高对比、足够大的点击区域和清楚的文字状态，不用持续动画表示服务运行。二维码和地址以当前实际监听地址生成；不展示无效或过期的可连接状态。

## UX-M1-002 主界面异常与生命周期

| 状态 | 主文案与操作 | 转移 |
| --- | --- | --- |
| 尚未授权 | “需要存储权限以保存和管理接收文件” / [授权] | 授权成功后尝试启动；拒绝后保留解释与重试 |
| WiFi 不可用 | “请连接 WiFi 后重试” / [重试] | WiFi 有效后启动 |
| 启动中 | “正在启动服务…” | 成功到已开启；失败显示原因 |
| 启动失败 | “服务启动失败：端口被占用 / 无法访问保存目录” / [重试] | 修复条件后重试 |
| 已开启 | UX-M1-001 | 停止、WiFi 丢失或界面不可见时停止 |
| 已停止 | “服务已停止” / [启动服务] | 重新启动；旧页面请求提示断开 |

按返回显示“关闭服务并退出？未完成的传输将中断。”按钮 [取消] [关闭并退出]；取消后继续服务，确认后停止监听和未完成接收，清理临时文件。切换到其他应用时依前台可见策略停止，不弹确认。重新进入重新取得地址，不自动恢复上传。屏幕保持唤醒只在服务界面可见且服务开启时生效。

## UX-M1-003 浏览器主页

```text
局域网文件传输
保存到阅读器 EInkTransfer 目录；支持任意类型文件。
仅在可信局域网使用，离开阅读器服务界面会停止传输。
[选择文件（可多选）]             [刷新列表]

本次上传
文件名             大小      状态 / 进度       操作
示例A.zip          12 MiB    上传中 35%        [取消]
示例B              0 B       等待              [取消]

设备上的文件
文件名             大小                        操作
示例C.txt          2 KiB                       [下载] [删除]
```

以上文件名均为虚构样例。窄屏允许行内换行或卡片呈现，文件名不得挤掉操作。文件选择器不设格式白名单，接受文件系统允许的合法名称。列表为空时显示“还没有接收文件，选择文件开始上传”。刷新失败保留上一次列表并明确“列表可能不是最新”。

## UX-M1-004 上传队列完整状态

| 状态 | 显示与操作 | 后续 |
| --- | --- | --- |
| 等待 | 文件名、大小、等待 / [取消] | 前项完成后开始；取消后变为已取消 |
| 上传中 | 文件名、大小、传输百分比 / [取消] | 请求体发送完不立即视为成功 |
| 正在保存 | “正在保存…” | 服务端确认写入成功后才标记成功 |
| 成功 | “上传成功” | 加入设备文件列表 |
| 已取消 | “已取消” | 不加入已完成文件列表；可重新选择 |
| 失败 | “上传失败：重名 / 空间不足 / 连接中断 / 文件名无效 / 服务异常” | 修复后重新选择该文件；不假成功 |

单个浏览器同时传输一个文件。某项失败或取消后继续处理其他可传输项；连接已经不可用时，剩余等待项标记“连接已断开，请恢复服务后重新选择”，不无限重试。进度只表示请求传输进展，服务端确认前保持“正在保存”。

重名提示：“文件已存在，未覆盖。请先删除原文件后重新上传。”队列同名：“该文件已在队列中。”不弹出自动覆盖选项，不改变原文件。非法文件名提示原因，不能因允许所有格式而放行路径穿越。

取消请求发出后，不能仅凭浏览器请求终止就断言文件已取消；必要时显示“正在确认取消结果…”，刷新设备列表核对。若服务端尚未提交，清理临时内容并显示已取消；若已提交，则保留文件并显示“文件已完成上传”。连接不可用导致无法确认时显示“结果待确认，请恢复连接后刷新”，不擅自删除文件或宣称取消成功。

## UX-M1-005 下载、删除和断线

- [下载] 触发浏览器附件下载；已被删除或连接失败时显示错误，不打开文件内容执行。
- [删除] 显示“删除‘<文件名>’？文件将从阅读器的 EInkTransfer 目录移除。”按钮 [取消] [删除]。删除请求期间避免重复操作；成功后移除该行；失败保留该行并显示原因。
- 页面无法连接：“无法连接阅读器。请确认同一 WiFi，并在阅读器打开传输界面，然后刷新。”保留可读页面，禁止把失败项显示为成功。

## UX-M1-006 阅读器接收文件列表

从“查看接收文件”进入本应用内列表，仍属于可见服务界面；只展示本应用目录已完成的普通文件名与大小，提供 [刷新] 和 [返回传输]。空状态与加载失败有独立文案。不在此页增加解析、阅读、安装、任意目录浏览或删除功能；文件下载和确认删除在浏览器完成。

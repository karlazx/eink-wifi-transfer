# M1：不限格式的局域网文件传输

状态：用户已于 2026-10-20 确认范围并要求继续开发；同时明确禁用 sdd-governance，不再执行其门禁。测试结果另见 TEST_REPORT.md。

## 目标与验收基线

用户在墨水屏阅读器打开应用后，同 WiFi 的手机或电脑用浏览器访问阅读器地址，即可传入任意类型文件，并查看、下载和删除本应用接收目录中的文件。

实机验收基线为 Likebook K78W、Android 8.1 / API 27。浏览器至少覆盖电脑 Chrome 和手机 Safari / Chrome 中的一种；准确浏览器与版本在测试记录中填写。M1 不承诺其他阅读器或新版 Android 的完整存储兼容性。

| REQ-M1-007 | 同名文件或队列同名项明确拒绝，不静默覆盖；其他文件继续上传。再次上传需先删除既有文件 | UAT-M1-007 |

“全部类型”指不按格式过滤，不意味着无限大小、不受存储空间约束、绕过文件系统命名约束或支持打开所有文件。单文件防护上限为 2 GiB（未做大文件实测），使用 32 KiB 缓冲流式传输，不能在未实测时宣称无限大。实现应流式传输，不将整个大文件载入内存。

## 明确不在 M1 范围

账号、云端中转、互联网访问、HTTPS、配对码、后台常驻服务、断点续传、文件夹上传、子目录浏览、任意目录选择、覆盖模式、自动重命名、书库集成、文件内容解析、APK 自动安装、网页拖拽、广告与统计均不纳入 M1。

HTTP 无认证，仅适用于可信局域网；同网用户在服务开启期间可能访问接收目录的文件并执行上传、下载、删除。应用界面及网页需说明这一使用条件，并提供明确停止服务入口。上传 HTML、APK 等文件只负责存储和附件下载。

## 已确认决策

1. 使用独立 `EInkTransfer` 接收目录，有意隔离原应用的 `/sdcard/WifiTransfer` 目录，不迁移既有文件。
2. 服务仅在应用界面可见时运行；返回保留退出确认，取消则继续服务，确认退出或切换应用会中断未完成传输。原应用仅确认了退出行为，切换应用即停是新应用明确的前台服务边界。
3. 拒绝重名而不覆盖；无账号及配对码的可信局域网服务。
4. 先交付可安装 APK、源码与中文使用说明；公开托管平台和仓库名称可在发布前确定，不阻碍本地实现。
5. 原“快速查看”跳到原阅读书架；新应用改为本应用接收目录文件列表，不依赖原书架。目录隔离、这一入口变化和前台服务边界均属于本次审批范围；不限格式是主要功能扩展。

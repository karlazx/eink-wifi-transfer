## 已闭合问题

1. 保留原应用返回关闭确认；明确切换应用停服是新应用候选边界，未冒充原应用实测事实。
2. 将独立目录、书架替代为接收列表、前台生命周期列为显式差异，不把“不限格式”描述为唯一变化。
3. 补充取消与提交竞态：服务端已提交则保留完成文件，结果无法确认则提示恢复连接后刷新，不伪报取消成功。
4. 需求、UX、UAT 统一为 M1 标识，保留可追踪映射。

## 仍需用户决定

G1 需用户批准 PRD 与 UX，尤其是独立 `EInkTransfer` 目录且不迁移原文件、接收列表替代原书架、界面不可见即停服、同名拒绝，以及可信局域网 HTTP 无认证的候选范围。批准该规格不等于验收产品，也不等于授权发布到某个远端账号。

技术方案需落实单文件上限、低内存流式收发、原子提交与临时文件清理、并发重名保护以及 Android 8.1 存储权限。上述实现尚无通过证据，不能把文档复审结论用于替代后续验证。

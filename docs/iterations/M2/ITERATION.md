# M2 · 文件访问体验与 v1.0.0

日期：2026-10-20。开发分支：`feature/m2-file-access-v1.0.0`，从 M1 完成后的 `main` 创建；实现与验证完成后合并 `main`，发布正式标签 `v1.0.0`。用户已禁用 sdd-governance，本迭代不使用其流程。

## 需求与最终行为

1. 阅读器“打开文件管理器”直接进入可用的文件管理器。Likebook 优先使用原厂公开入口；其他已知管理器作为回退，找不到时提示用户。接收位置仍为共享存储 `EInkTransfer`；具体打开页面由文件管理器决定，实机进入原厂分类首页。
2. 网页默认“接收目录”，保留上传、下载、确认删除；增加“全部文件 · 只读”，逐层浏览可读共享存储并下载，不提供删除。不是 Android 系统根目录，也无法读取其他应用的私有存储。
3. 上传限制提升到 5 GiB，前后端统一为 5,368,709,120 字节，服务端使用 long 与流式写入，仍受剩余空间及文件系统限制。按用户要求不进行大文件实传测试。
4. 依据用户最终修正，上传后不自动处理文件，也不请求安装权限；用户通过文件管理器自行打开或安装。

## 实现与边界

- `GET /api/storage?path=...` 返回相对共享存储根目录的列表；`GET /api/storage/file?path=...` 附件下载。
- 两个新接口对非 GET 方法返回 405；拒绝越界、符号链接、临时上传目录及不可读路径；原删除接口只允许接收目录下的单文件名称。
- 全部文件页没有上传/删除入口；顶部上传区继续保存到接收目录，不随浏览目录改变。
- 打开文件管理器会触发应用离开前台并停止服务，未完成传输中断；返回应用后按原服务状态恢复。需先完成上传再打开管理器。
- 当前为可信局域网 HTTP 服务，无配对认证。服务开启期间同网用户可读取共享存储，使用后停止服务。
- 正式构建使用 `.signing/` 内长期证书，私钥与配置不入库。预览签名迁移需要首次卸载重装，后续相同证书覆盖升级。
